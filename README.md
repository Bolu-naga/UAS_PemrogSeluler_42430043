# Ford Neon Garage

Ford Neon Garage adalah aplikasi katalog mobil Ford berbasis Android yang dibuat untuk tugas Pemrograman Seluler. Aplikasi ini menampilkan berbagai model mobil Ford dengan konsep UI/UX dark futuristic digital showroom.

## Konsep Aplikasi

Aplikasi ini menggunakan tema Ford Neon Garage, yaitu katalog mobil bergaya premium showroom dengan warna gelap, aksen biru neon, card glassmorphism, dan tampilan detail mobil yang modern.

## Fitur

- Daftar katalog mobil Ford
- 30 model mobil Ford
- Search mobil berdasarkan nama, kategori, mesin, tenaga, harga, bahan bakar, dan kursi
- Sort A-Z dan Z-A
- Filter kategori mobil
- Custom car card
- Detail mobil lengkap
- Favorite button
- Layout portrait dan landscape
- Dark futuristic UI
- Animasi transisi antar halaman
