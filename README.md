## Topik Aplikasi

**Ford Garage** adalah aplikasi katalog mobil Ford berbasis Android yang dibuat menggunakan Kotlin dan XML Layout di Android Studio.

Aplikasi ini menampilkan berbagai koleksi mobil Ford, mulai dari mobil sport, SUV, truck, electric car, hybrid, classic car, hingga mobil legend seperti **Ford GT40 Mark II Ken Miles**.

Aplikasi ini menggunakan konsep desain **dark futuristic digital showroom** dengan tampilan modern, card mobil premium, aksen warna biru neon, serta dukungan tampilan portrait dan landscape.

---

## Deskripsi Aplikasi

Aplikasi Ford Garage dibuat untuk membantu pengguna melihat katalog mobil Ford secara interaktif. Pengguna dapat melihat daftar mobil, mencari mobil tertentu, memfilter berdasarkan kategori, mengurutkan data, melihat detail spesifikasi, dan melihat gambar masing-masing mobil.

Setiap mobil memiliki informasi seperti:

- Nama mobil
- Kategori
- Mesin
- Tenaga
- Harga estimasi
- Tagline
- Transmisi
- Bahan bakar
- Kapasitas kursi
- Foto mobil

---

## Fitur Aplikasi

- Splash screen dengan logo Ford
- Katalog 30 mobil Ford
- Foto masing-masing mobil
- Search data mobil
- Filter kategori mobil
- Sort data A-Z dan Z-A
- Custom card untuk setiap mobil
- Halaman detail mobil
- Favorite button
- Empty state jika data tidak ditemukan
- Tampilan portrait dan landscape
- Animasi transisi antar halaman
- Try-catch untuk menangani error
- Logcat untuk debugging dan menampilkan NIM
